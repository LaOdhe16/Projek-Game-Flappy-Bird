# 🐦 Flappy Bird Game

A simple Flappy Bird game project developed using Python. The game challenges players to control a bird, avoid obstacles, and achieve the highest score possible.

## 📖 About the Project

**Flappy Bird Game** is a game development project inspired by the classic Flappy Bird gameplay. Players must keep the bird flying by controlling its movement while navigating through obstacles.

The objective is to survive as long as possible without colliding with obstacles. This project serves as an opportunity to explore game development concepts, programming logic, and interactive gameplay using Python.

## ✨ Features

- **Bird Movement** — Control the bird's movement throughout the game.
- **Obstacle Avoidance** — Navigate through obstacles without colliding with them.
- **Score Challenge** — Challenge yourself to achieve a higher score.
- **Game Assets** — Includes an assets directory for game resources.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Python 3.x
- Git

You may also need additional Python libraries depending on the dependencies used in the project.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/LaOdhe16/Projek-Game-Flappy-Bird.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Projek-Game-Flappy-Bird
   ```

3. Install the required dependencies, if applicable:

   ```bash
   pip install -r requirements.txt
   ```

   If the project does not include a `requirements.txt` file, install the libraries required by `app.py`.

4. Run the game:

   ```bash
   python app.py
   ```

## 🎮 How to Play

1. Start the game by running the application.
2. Control the bird using the input supported by the game.
3. Avoid obstacles and try to stay in the air.
4. Keep playing to achieve the highest score possible.
5. Avoid collisions to keep your run going.

> Check the in-game instructions or source code for the exact controls.
